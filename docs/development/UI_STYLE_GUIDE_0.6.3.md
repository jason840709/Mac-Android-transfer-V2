# Android 傳輸 V2 0.6.3 UI Style Guide — readable-ui-r2

## 本輪原則

0.6.3-readable-ui-r2 不再全面提亮 0.6.2 的低飽和語意色。

使用者已確認 0.6.2 muted-ui-r1 的整體配色、檔案分類色與狀態層級較自然，因此本輪把**所有一般介面與語意顏色恢復到 0.6.2**。唯一的色彩例外是「內部共用儲存空間」的容量進度條：它在超深色 sidebar 上需要更高明度，因此獨立使用淺紫羅蘭色。

## 色彩規則

### 一般 Accent

維持 0.6.2：

- Light: `#7884B4`
- Dark: `#94A0C8`

它負責選取、連線與一般互動提示，不應和容量條競爭注意力。

### 儲存空間進度條

這是本輪唯一新增的 chromatic delta：

- Light: `#9485B6`
- Dark: `#B8A9D8`

方向是**淺色、低飽和、偏紫羅蘭**。Dark Mode 必須比一般 Accent 明顯更亮，讓使用者在超深色介面中一眼看出容量百分比，同時又不能變成高飽和紫色。

進度條底軌使用中性的 `Color.secondary.opacity(0.20)`，避免再增加一個有色塊。

### 其餘語意色

全部恢復 0.6.2，包括：

- 資料夾、圖片、影片、音訊、PDF、壓縮檔、文件、App 類型色
- 上傳、下載、成功、失敗、警告、能力提示

也就是說，本輪不再做 0.6.3-readable-ui-r1 的全面 Dark Mode 提亮。

## 文字大小

保留 0.6.3 的「顯示方式 → 文字大小 → 小 / 中 / 大」。這部分沒有回退。

- 小：高資訊密度
- 中：預設，接近 Finder 日常閱讀尺寸
- 大：提高長時間瀏覽與高解析度螢幕可讀性

文字尺寸調整必須同步影響 sidebar、Finder 式檔案表格、表頭、麵包屑、傳輸面板與設定畫面，不改變 Finder 拖曳傳輸核心。

## 穩定性邊界

本輪只允許修改 Palette 與相關驗證／文件。不得修改：

- 0.6.0 Finder exact-destination 傳輸邏輯
- File Promise 行為
- libmtp / libusb
- 自動開啟 Agent
- 排序與 selection 模型
- 傳輸面板完成／收合語意
